# Улюблені локації (Places App)

Це вебзастосунок на базі Django, який дозволяє переглядати список цікавих міських локацій, а також додавати власні місця. 

Особливістю проєкту є використання **Django Sessions**: додані користувачем місця зберігаються локально в його сесії, не впливаючи на загальну базу даних (редакційний список) для інших відвідувачів.

## Основний функціонал
* Перегляд базового (редакційного) списку локацій.
* Додавання користувацьких місць через вебформу.
* Фільтрація списку (Усі / Редакційні / Мої).
* Очищення сесії (видалення доданих користувачем місць).
